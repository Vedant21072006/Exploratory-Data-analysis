# Titanic Exploratory Data Analysis (EDA)

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Python.  
The goal is to understand the structure of the dataset, analyze categorical and numerical variables through univariate analysis, and explore relationships with survival using bivariate analysis and visualizations.

---

## 📌 Objectives

- Load and explore the Titanic dataset  
- Identify categorical and numerical features  
- Perform univariate analysis on categorical variables using count plots  
- Perform univariate analysis on numerical variables using histograms, KDE, and box plots  
- Perform bivariate analysis to study survival patterns using hue-based bar charts  
- Analyze distribution properties such as skewness and central tendency  

---

## 🧰 Tools & Libraries

- Python  
- Pandas  
- Seaborn  
- Matplotlib  
- NumPy
